# Docs

| file | what it is |
|---|---|
| `DESIGN.md` | the art direction ("Capital Cypher"), the three planes, the signature moments, motion rules, the IA |
| `BRAND-SYSTEM.md` | colour, type, marks and surfaces, with contrast notes |
| `PITCH-NOTES.md` | kept exactly, fixed (live-site defects), new pages for client approval, questions for the client |
| `CHANGE-LOG.md` | a decision for every section of the old site (generated from `audit/change-control.json`) |
| `MEDIA.md` | every generated or AI-enlarged image, with model, request id and prompt |
| `DEPLOY.md` | preview and production deployment, redirects, headers, pre-launch checklist |
| `PUBLISH.md` | what was published, when, and the checks run before it |
